# Built-in colour books

AutoCAD `.acb` colour books built into the Select Color panel. Each file
carries its source and licence in its header comment.

| File | Book | Licence |
|---|---|---|
| `ral-classic.acb` | RAL CLASSIC, 216 approximate sRGB values | CC BY-SA 4.0, adapted from Wikipedia, "List of RAL colours" |
| `css-colors.acb` | CSS COLORS, the 148 CSS named colours | Values from the W3C CSS Color Module Level 4 |

RAL is a registered trademark of RAL gGmbH. The RAL values are approximate
screen representations, not colour-binding references, and are not
affiliated with, endorsed by or licensed by RAL gGmbH.
